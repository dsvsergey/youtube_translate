## Етап 3 — Pro-тариф (~$3–5/міс)

Що входить у Pro:
- Розпізнавання мови без власного ключа (наш ключ Deepgram на сервері).
- Нейронні голоси (ElevenLabs / OpenAI TTS / Google Cloud TTS) замість `speechSynthesis`.
- Офіційний перекладач (DeepL / Google Cloud Translation) замість неофіційного ендпоінта.
- Ліміт хвилин на місяць (безліміт збитковий).

Технічно:
- Оплата: ExtensionPay (на базі Stripe) або Lemon Squeezy / Paddle — вони беруть на себе податки (VAT). Chrome Web Store власних платежів більше не має.
- Бекенд-проксі (Supabase Edge Functions або Cloudflare Workers): зберігає ключі API, перевіряє підписку, рахує хвилини.
- Оновити `PRIVACY.md` і опис у магазині (платні функції, сервер, платежі).

Юніт-економіка (орієнтовно):
- Deepgram STT: ~$0.25–0.45 за годину аудіо.
- Нейронний TTS: від ~$0.5 до кількох $ за годину.

## Етап 4 — Розширення ніш (пізніше)

- Режим для вивчення мов: оригінал + переклад, збереження слів, експорт.
- Інші платформи: Twitch, Vimeo, Coursera, Udemy.
- B2B: мовні школи, освітній контент.

## Ризики

- Неофіційний ендпоінт Google Translate може обмежити або закрити доступ — для Pro потрібен офіційний API.
- Конкуренти: закадровий переклад у Яндекс.Браузері, автодублювання YouTube. Переваги: якість голосу, українська мова, live-стріми, робота прямо в Chrome.
